# Tessera

Language drills for Latin, Spanish, Italian and Portuguese.

- Each unit: a short pattern (grammar) note, 10 high-frequency words, 6 sentences, 3 cloze items, one reading passage.
- Spaced repetition: every item is scheduled at 1, 3, 7, 16, 35 and 90 days. Typed and built answers advance an item; recognition answers only up to the second box. A miss resets it and brings it back in 10 minutes.
- Exercises: new-word introduction with expanding spacing, typed recall, sentence building, cloze, dictation, say-it-aloud with self-check, reading comprehension, free translation.
- Progress is stored in the browser (localStorage). Serve this folder with GitHub Pages and add it to your home screen.
